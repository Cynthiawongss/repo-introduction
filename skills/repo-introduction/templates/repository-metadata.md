# 仓库与发布信息（内部工作稿）

| 字段 | 填写建议 | 当前值 |
|---|---|---|
| 仓库名 | 尊重已有名称；新名称简短、可辨认、与入口一致 | |
| 英文 About | 一句说明具体用途，不堆形容词 | |
| 中文简介 | 同一事实，可供中文 README 或介绍使用 | |
| Topics | 少量与真实用途和类型有关的标签 | |
| Homepage | 真实可访问的演示或文档；没有就不填 | |
| README 默认语言 | 本用户默认英文，链接中文版 | |
| 封面 | 已选定项目资源路径与说明 | |
| 版本状态 | 以项目实际状态为准，不自动沿用 v0.1.0 | |
| 许可证 | 沿用现有授权或按用户决定；不默认宣称 MIT | |
| 可见性与账号 | 当前任务明确授权的值 | |

Release 仅在需要发布版本／安装包时创建：写明这版能做什么、包含哪些文件、开始使用方式、已验证范围和重要限制。不要把制作聊天过程当成版本说明。

发布后填写：仓库 URL、版本 URL、最终提交、封面与下载包核对结果。未发布就写“未发布”。
